Schedules set regular check-in calls for your loved one. Reminders are a separate feature with their own timing and use cases.

In this section, you’ll learn how to:

- Create and manage call schedules
- Set up reminders and recurring patterns
- Skip, snooze, or reschedule a call
- Set quiet hours for peace and rest
