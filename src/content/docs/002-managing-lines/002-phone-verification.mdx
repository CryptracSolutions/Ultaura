We verify each phone number before calls begin. This protects safety and consent.

## How Verification Works

1. We send a 6-digit code by text message.
2. Enter the code in the dashboard.
3. Verification is complete.

**For landlines:** Choose “Call me instead” to get the code by voice call.

## Tips

- Let your loved one know to expect the code.
- Codes expire after a short time. You can request a new one.
- If the code does not arrive, try again in a few minutes.

Your loved one can stop calls at any time by pressing 9 during a call or asking Ultaura to stop.

For help, see [Verification Problems](/docs/troubleshooting/verification-problems).
