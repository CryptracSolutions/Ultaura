Vacation Mode pauses scheduled calls and reminders for a date range.

## When to Use It

- Travel or vacation
- Hospital stays
- Visiting family

## Compare Your Options

- **Vacation Mode:** Planned time away. Pauses scheduled calls and reminders during the date range.
- **Skip Next Call:** One-time skip. Pauses the next scheduled call only.
- **Snooze Call:** Need a different time today. Sets a new time for today’s call.

## How to Set Vacation Mode

1. Go to **Line Settings**.
2. Open **Vacation**.
3. Add start and end dates.
4. Save changes.

Calls resume automatically after the end date.
