---

Phone verification is required before calls begin. Use these steps if the code is not working.

## Code Not Received

- Check that the phone number is correct
- For landlines, choose the voice call option
- Wait a few minutes and try again
- Check for call or text blocking

## Code Expired

Verification codes expire after a short time. Request a new code and try again.

## Invalid Code

- Enter the digits only
- Double-check for typos
- Request a new code if needed

## Too Many Attempts

Wait 30 minutes and try again. This protects against abuse.
